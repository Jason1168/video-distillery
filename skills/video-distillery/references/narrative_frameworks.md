# Narrative Frameworks Reference
*Video Distillery — Screenwriting & Storytelling Structures*

---

## 1. THE THREE-ACT STRUCTURE

```
Act 1 (25%) → Inciting Incident → Act 2 (50%) → Climax → Act 3 (25%)
     Setup                            Confrontation                Resolution
```

### For Brand Films / Short Videos
| Phase | Timecode (3-min film) | Function |
|-------|----------------------|----------|
| Hook | 0:00–0:15 | Grab attention immediately |
| World | 0:15–0:45 | Establish character/world |
| Inciting Incident | 0:45–1:00 | The problem/change that matters |
| Rising Action | 1:00–2:00 | Build tension, show struggle |
| Climax | 2:00–2:30 | Peak emotional moment |
| Resolution | 2:30–2:50 | New equilibrium |
| Final Image | 2:50–3:00 | Last image = emotional echo of theme |

**Rule**: First and last image should rhyme visually and thematically.

---

## 2. IN MEDIA RES (Start in the Middle)

```
Peak Moment → Flashback Setup → Return to Peak → Resolution
```

Best for: Action, thriller, compelling personal stories
Effect: Instant tension, audience immediately invested

**Example Structure** (2-min video):
- 0:00–0:20: We see the peak moment (crisis/triumph)
- 0:20–1:20: Flashback — how we got here
- 1:20–1:40: Return to that moment, now fully contextualized
- 1:40–2:00: Resolution / what it means

---

## 3. THE HERO'S JOURNEY (Documentary / Character Study)

```
Ordinary World → Call → Refusal → Mentor → Threshold → 
Tests → Ordeal → Reward → Road Back → Resurrection → Return
```

**Compressed for Short Form** (documentary short):
1. **Who they are** (ordinary world)
2. **The challenge** (call/inciting incident)
3. **Why it's hard** (trials, obstacles)
4. **The turning point** (ordeal/realization)
5. **Who they became** (transformation/return)

---

## 4. POETIC / ESSAYISTIC STRUCTURE

No traditional narrative. Association-based logic.
```
Image A → Feeling → Image B → Contradiction → Image C → Synthesis
```

Best for: Art films, experimental work, music videos, brand films with abstract concepts
Key principle: Juxtaposition creates meaning. The cut IS the argument.

**Building Blocks**:
- Thematic repetition with variation
- Visual motifs that evolve
- Emotional escalation without plot
- Strong opening and closing images

---

## 5. PROBLEM → INSIGHT → TRANSFORMATION (Corporate/Brand)

```
Pain Point → Empathy → Solution Reveal → New World
```

**Standard Beats**:
1. Show the pain (don't name it yet — feel it)
2. Acknowledge the person feeling it (empathy)
3. The insight/pivot moment
4. The solution in action
5. Transformed world / emotional resolution
6. Call to action (implicit or explicit)

---

## 6. PARALLEL STORIES (Cross-Cutting Structure)

Two or more storylines intercut, converging at climax.
```
Story A → Story B → Story A → Story B → [Convergence] → Resolution
```

Best for: Showing connection between disparate people/places, contrast, theme exploration.

---

## 7. THE KISHŌTENKETSU (Japanese 4-Act, No Conflict)

```
Ki (起) → Shō (承) → Ten (転) → Ketsu (結)
Introduce → Develop → Twist/Turn → Reconcile
```

The twist is not conflict — it's an unexpected perspective shift.
Best for: Japanese aesthetic, meditative films, non-Western narratives.

## 8. SCREENWRITING PRINCIPLES FOR DIRECTORS

### Show, Don't Tell (Visual Priority)
Every expository line of narration: ask "can I show this instead?"
- Instead of "She was lonely" → show an empty dinner table set for two
- Instead of "They had been working for years" → show worn equipment, grey hair

### Subtext: Characters Don't Say What They Mean
When emotion is high, characters:
- Talk about something unrelated (the displaced conversation)
- Use metaphor/analogy
- Go silent
- Talk about the past when they mean the present

### The Visual Metaphor System
Every thematic element should have a physical manifestation:
| Theme | Physical Metaphor Example |
|-------|--------------------------|
| Freedom | Open windows, birds, wide lenses |
| Imprisonment | Tight frames, bars, narrow hallways |
| Growth | Plants, dawn light, rising camera |
| Memory | Faded color, shallow DOF, slow motion |
| Connection | Hands touching, shared frame, matched cuts |
| Isolation | Character small in frame, back to camera |

### Economy of Storytelling
Every scene must serve ≥2 functions:
- Advance plot AND reveal character
- Create atmosphere AND deliver information
- Build tension AND show relationship

### Escalation Principle
Each successive scene should:
- Raise the stakes (more to lose)
- Deepen understanding (new dimension revealed)
- Or change the direction (surprise that recontextualizes)

## 9. THE DIRECTOR'S SHOT SELECTION LOGIC

**For every scene, ask in order**:
1. What is the character FEELING?
2. What do I want the AUDIENCE to feel?
3. What is the most HONEST shot that serves both?
4. What is the SUBTEXT of this moment?
5. How does this shot relate to the PREVIOUS and NEXT shot?

**Shot selection is emotion selection.**
The camera position is a point of view — it implies a relationship.
- Low angle = power, threat, awe
- High angle = vulnerability, submission, overview
- Eye level = equality, neutrality, documentary truth
- Dutch angle = psychological unease

---

## 10. THE RHYTHM OF A GREAT FILM

Great films breathe. They accelerate and decelerate deliberately.

```
Slow (establish) → Build → Fast (peak) → Release → Slow (resolve)
```

**Common Rhythm Mistakes**:
- Starting too fast (no room to build)
- Sustaining peak energy too long (audience fatigues)
- Ending abruptly (no release)
- Never changing pace (monotony)

**Music as Rhythm Map**: Map the music's natural arc — that IS your edit rhythm.

---

## 11. THE FIRST AND LAST FRAME RULE

**Opening image**: Should encapsulate the theme or the protagonist's current state.
**Closing image**: Should show the transformation. It should rhyme with the opening.

The gap between first and last frame = the story.

Examples:
- Opens on character looking DOWN → closes on character looking UP
- Opens on CLOSED door → closes on OPEN window
- Opens on SILENCE → closes on LAUGHTER
