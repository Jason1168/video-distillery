## 📋 Quick Reference: Essential Starter Stack

These are well-established tools to start with immediately:

| Tool | Purpose | Install |
|------|---------|---------|
| **FFmpeg** | Universal video processing | `brew install ffmpeg` |
| **yt-dlp** | Download reference videos | `pip install yt-dlp` |
| **Whisper** | Auto-transcribe / subtitle | `pip install openai-whisper` |
| **scenedetect** | Shot/scene boundary detection | `pip install scenedetect` |
| **Pillow/PIL** | Frame extraction & analysis | `pip install Pillow` |
| **moviepy** | Python video editing | `pip install moviepy` |
| **imageio-ffmpeg** | Video I/O for Python | `pip install imageio-ffmpeg` |
| **colour-science** | Professional color math | `pip install colour-science` |
| **librosa** | Audio analysis (beat detection) | `pip install librosa` |
| **demucs** | AI audio stem separation | `pip install demucs` |
