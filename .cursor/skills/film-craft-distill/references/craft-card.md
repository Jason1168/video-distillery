# 卡片

## 远观

没看过画面时只用这一份。不要写景别、切点数、调色和镜头长度。

```markdown
# 标题
- 来源:
- 链接:
- 类型假设: 未看画面
- 页面上确实写了的一点:
- 可以迁移的形式假设:
- 不该抄的:
- 适合我们哪类成片:
```

## 全片

测量和接触表看完再写。

```markdown
# 标题
- 参考:
- 类型:
- 控制思想:
- 结尾要让人相信:
- 开场 8 秒:
- 转折的时间码和造成转折的信息:
- 不抄的三样:
- 要超过参考的维度:
- 交付: 画幅、帧率、时长、响度
```
